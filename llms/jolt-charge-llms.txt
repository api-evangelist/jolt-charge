# JOLT

> JOLT is a Sydney-headquartered electric vehicle charging network operator running free-to-start kerbside DC fast chargers across Australia, New Zealand, Canada, the United Kingdom and the United States. The first 7kWh of each day's charging is free to the driver over CCS2 or CHAdeMO, funded by the digital out-of-home advertising screens on the charger, which makes JOLT simultaneously a charge point operator and a media network. JOLT publishes NO public API, no developer programme, no documentation and no open data. This file exists so an agent does not waste calls looking for one.

## API posture (verified 2026-07-27)

- **Public API: none.** No developer portal, no API documentation, no OpenAPI/Swagger, no GraphQL, no AsyncAPI, no MCP server, no Postman collection, no SDK on any public registry (npm, PyPI searched — zero first-party packages).
- **There IS a private API host.** `https://api.joltcharge.com/v1/*` is fronted by AWS API Gateway and answers `401 {"message":"Unauthorized"}` on every path and method probed anonymously — it is the backend for the JOLT mobile app and website forms, not a product API. The host ROOT (`https://api.joltcharge.com/`) is a static S3 page that meta-refreshes to the app start page; every non-`/v1/` path there returns S3 `403 AccessDenied`.
- **No /.well-known/ documents.** security.txt, openid-configuration, oauth-authorization-server, oauth-protected-resource, api-catalog and ai-plugin.json all miss on every host. No `llms.txt` is published by JOLT (this file is generated by API Evangelist).
- **No open data.** No charger-location feed, no availability endpoint, no session/utilisation dataset, no emissions data. The public charger map renders through the Google Maps JavaScript API with no JOLT-owned data endpoint.
- **No standards conformance published.** No OCPI, OCPP, ISO 15118, OpenADR, Green Button/ESPI or Consumer Data Right (energy) conformance. CCS2 and CHAdeMO are named, but those are connector standards, not data standards.
- **Not a CDR energy data holder.** The Australian CDR Register's public energy data-holder brands endpoint returned 84 brands on 2026-07-27; none is JOLT.

## How a developer or agent actually gets in

There is no route in. There is no sign-up for a key, no application form, no partner API programme documented. Consumer onboarding is the only self-serve path: download the JOLT app, register, and optionally take a JOLT Plus membership in-app. Any data or integration conversation starts at the generic contact form.

- [Contact JOLT](https://joltcharge.com/au/contact/): the only route to a commercial or data conversation
- [Start / app registration](https://joltcharge.com/au/start/): consumer self-serve onboarding
- [JOLT Plus](https://joltcharge.com/au/jolt-plus/): membership tiers and published pricing
- [Find a charger](https://joltcharge.com/au/find-a-charger/): map UI, no data feed behind it
